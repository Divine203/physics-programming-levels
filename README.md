# Levels of Physics Programming

This project is a small browser-based physics playground inspired by the ideas from The Nature of Code. Each level explores a different physics concept, from simple gravity and collisions to soft-body and cloth simulations.

## How to run

Open the project in a browser and switch between the example scripts as needed:

- Open `index.html` to run the default canvas scene.

## Levels

### Level 1 - Gravity and Falling Bodies
A simple box falls under gravity and settles on the ground. This introduces the basics of motion, acceleration, and collision with a floor.

### Level 2 - Basic Collision Between Two Boxes
Two moving boxes collide, separate, and exchange velocity. This demonstrates the fundamentals of rigid-body overlap and response.

### Level 3 - Mass, Restitution, and Elastic Collisions
The collisions become more realistic with restitution, mass-based impulse response, and wall bounces. This level focuses on how objects react when they hit each other.

### Level 4 - Mixed Shape Collision
Boxes and circles interact in the same scene. It introduces different collision types and shows how physics systems can handle multiple object forms.

### Level 5 - Rotating Rigid Bodies
This level adds rotation, angular velocity, and rigid-body collision detection. Objects can spin and collide using more advanced separation methods.

### Level 6 - Friction, Torque, and Advanced Rigid Bodies
Physics gets more advanced with friction, impulse resolution, and rotational effects. This level models realistic surface contact and object response during collisions.

### Level 7 - Verlet Physics and Soft Body Character
A soft, spring-based body is built from connected points. This shows how constraint solving and verlet integration can create a flexible humanoid form.

### Level 7 Car - Car Impact Simulation
A moving car collides with the soft body. This demonstrates how a rigid object can interact with a deformable body and stop it with physical impact.

### Level 8 - Cloth Simulation
A cloth grid is simulated with springs and constraints, with wind and drag controls. This level explores soft surfaces, tension, and interactive deformation.

### Level 9 - Interactive Soft Body
A soft mesh is suspended and deformed by mouse interaction. It highlights constraint-based motion and the way points can be pushed and pulled in a physically believable way.
